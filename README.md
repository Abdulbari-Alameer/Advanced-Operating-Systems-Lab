# Advanced Operating Systems Lab

Operating systems lab work from my Master's in Computer Science & Engineering at Tezpur University, written in C and Python. Each folder has its own README with build and run instructions.

## Projects

| Project | Summary | Language |
|---|---|---|
| [Simple Shell](Simple_Shell) | `myshell`, a small custom Unix shell that reads and runs user commands | C |
| [RPC User Session Monitor](RPC-User-Session-Monitor) | A `who`-style command: lists logged-in users locally, then fetches them from a remote server using Sun RPC (`rpcgen`) | C |
| [Multithreaded Client-Server](Multithreaded-Client-Server) | A concurrent client-server framework that uses a thread pool to serve several clients | Python |
